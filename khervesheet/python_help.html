Python in KherveSheet

Write real Python inside a cell — 118 commented examples.

Getting started Reading the grid — ks() NumPy & math Statistics Data analysis & signals Curve fitting & regression Linear algebra Plots — basics Plots — advanced Physics Chemistry Engineering & signals Finance & misc Simulations & Monte Carlo

How it works. Type =PY in a cell (or Insert → Python Cell); the formula bar becomes a code editor. Press Ctrl+Enter to run. The cell's value is the value of the last line (if it's an expression). All Python cells share one workbook namespace, so a function defined in one cell is callable from any other. Every example below has comments explaining what each line does.

Read the grid with ks("A1") (one cell) or ks("A1:B10") (a range → NumPy array). Output: a number/text shows in the cell; a list spills into neighbouring cells; a NumPy array / DataFrame is held live in the cell; a matplotlib figure is embedded as a picture. np, plt and (if installed) pd / scipy are ready to use.

Python functions as formulas (UDFs). A function you def in a =PY cell can be called from an ordinary formula: define def discount(p, r): return p * (1 - r), then write =DISCOUNT(A2, 0.1) anywhere — case-insensitive, and built-in functions are never overridden.
Pop-out editor. Click the button next to the green PY strip for a larger editor with line numbers, autocomplete (Ctrl+Space), comment toggle (Ctrl+/), a Pick cell button to click-insert a ks("…") reference, and an output pane. Run keeps the window open so you can iterate.

Reading the grid — ks()

ks("A1")value of one cell
ks("A1:A10")1-D NumPy array
ks("A1:C5")2-D NumPy array
ks("Sheet2!B2")value from another sheet
Writing back: ks_set("C1", value) (alias write) pushes a result into the grid — a scalar fills the range, a 1-D array writes down a column, a 2-D array writes a block. The cell running the code is never overwritten, e.g. ks_set("D1:D50", np.cumsum(ks("A1:A50"))).

Simulations & Monte Carlo

What is Monte Carlo? Instead of solving a problem with a formula, you draw many random samples and average the outcomes — the answer converges as the number of samples grows. Always seed the generator (np.random.default_rng(seed)) so results are reproducible. The shipped Examples → Python Examples menu has ready-to-open workbooks for all of these (Simulations, Finance Simulations, Physics Simulations, Materials Science).

103Estimate π by random darts

Throw points in a square; the fraction landing in the quarter circle is π/4.

# Monte Carlo estimate of pi
rng = np.random.default_rng(0)
p = rng.random((100000, 2))          # random points in the unit square
inside = (p[:, 0]**2 + p[:, 1]**2) <= 1   # inside the quarter circle?
4 * inside.mean()                    # -> approx 3.14159

104Monte Carlo integration

Average the function at random points, times the interval width.

# estimate the integral of sin(x)^2 on [0, pi]
rng = np.random.default_rng(1)
a, b, N = 0, np.pi, 100000
x = rng.uniform(a, b, N)             # random sample points
(b - a) * np.mean(np.sin(x)**2)      # ~ pi/2

105Buffon's needle

Drop needles on ruled lines; the crossing fraction gives π.

# estimate pi from needle crossings
rng = np.random.default_rng(2)
N, L, d = 100000, 1.0, 2.0           # drops, needle length, line spacing
mid = rng.uniform(0, d/2, N)         # distance of centre to nearest line
ang = rng.uniform(0, np.pi/2, N)     # needle angle
cross = mid <= (L/2)*np.sin(ang)     # does it cross a line?
2*L / (d * cross.mean())             # ~ pi

106Law of large numbers (dice)

The running average of many dice rolls converges to 3.5.

# rolling average approaches the true mean 3.5
rng = np.random.default_rng(3)
rolls = rng.integers(1, 7, 5000)     # 5000 dice rolls
avg = np.cumsum(rolls) / np.arange(1, rolls.size + 1)
plt.plot(avg); plt.axhline(3.5, color="#ed7d31", ls="--")
plt.gcf()

110Stock price paths (GBM)

Geometric Brownian motion — the standard model for asset prices.

# 50 simulated price paths over a year
rng = np.random.default_rng(7)
S0, mu, sig, days, n = 100, 0.08, 0.2, 252, 50
dt = 1/days
z = rng.normal(size=(n, days))
incr = (mu - 0.5*sig*sig)*dt + sig*np.sqrt(dt)*z
paths = S0*np.exp(np.cumsum(incr, axis=1))
plt.plot(paths.T, lw=0.6, alpha=0.6); plt.gcf()

111Monte Carlo option price

Average the discounted payoff over many simulated final prices.

# price a European call by simulation
rng = np.random.default_rng(8)
S0, K, sig, r, T, n = 100, 105, 0.2, 0.03, 1.0, 200000
ST = S0*np.exp((r-0.5*sig*sig)*T + sig*np.sqrt(T)*rng.normal(size=n))
payoff = np.maximum(ST - K, 0)       # call payoff at expiry
float(np.exp(-r*T) * payoff.mean())  # discounted average

112Value at Risk (VaR)

The loss not exceeded with, say, 95% confidence.

# 1-day 95% VaR from simulated returns
rng = np.random.default_rng(9)
value, mu, sig, n = 100000, 0.0005, 0.02, 100000
pnl = value * rng.normal(mu, sig, n)     # simulated profit/loss

115Ising model (magnetism)

Spins flip by the Metropolis rule; below T_c they align.

# net magnetization of a small 2-D lattice
rng = np.random.default_rng(12)
L, T, sweeps = 20, 2.0, 200
s = rng.choice([-1, 1], (L, L))
for _ in range(sweeps):
    i, j = rng.integers(0, L, 2)
    nb = s[(i+1)%L, j] + s[(i-1)%L, j] + s[i, (j+1)%L] + s[i, (j-1)%L]
    dE = 2 * s[i, j] * nb            # energy change if flipped
    if dE <= 0 or rng.random() < np.exp(-dE/T):
        s[i, j] *= -1   # accept the flip
float(abs(s.mean()))                 # |magnetization| per spin

117SIR epidemic

Susceptible/Infected/Recovered populations over time.

# integrate the SIR model with simple Euler steps
N, beta, gamma = 1000, 0.4, 0.1
S, I, R = N-1, 1, 0
hist = []
for _ in range(1600):
    dS = -beta*S*I/N; dI = beta*S*I/N - gamma*I; dR = gamma*I
    S += 0.1*dS; I += 0.1*dI; R += 0.1*dR
    hist.append((S, I, R))
plt.plot(hist); plt.legend(["S", "I", "R"]); plt.gcf()

118Estimating e

On average it takes e uniform(0,1) draws to sum past 1.

# Monte Carlo estimate of Euler's number
rng = np.random.default_rng(14)
trials = 200000
counts = []
for _ in range(trials):
    s = c = 0
    while s <= 1:
        s += rng.random(); c += 1   # draw until the sum exceeds 1
    counts.append(c)
np.mean(counts)                  # ~ 2.71828
