Python in KherveSheet

Write real Python inside a cell — 100 worked examples.

Getting started Reading the grid — ks() NumPy & math Statistics Data analysis & signals Curve fitting & regression Linear algebra Plots — basics Plots — advanced Physics Chemistry Engineering & signals Finance & misc

How it works. Type =PY in a cell (or Insert → Python Cell); the formula bar becomes a code editor. Press Ctrl+Enter to run. The cell's value is the value of the last line (if it's an expression). All Python cells share one workbook namespace, so a function defined in one cell is callable from any other.

Read the grid with ks("A1") (one cell) or ks("A1:B10") (a range → NumPy array). xl() and cell() are aliases. Output: a number/text shows in the cell; a list spills into neighbouring cells; a NumPy array / DataFrame / object is held live in the cell (re-read with ks); a matplotlib figure is embedded as a picture. np, plt and (if installed) pd / scipy are ready to use.

43Polynomial fit, evaluated

44Nonlinear fit (exponential)

from scipy.optimize import curve_fit
def f(x, a, b): return a * np.exp(b * x)

45Gaussian fit

from scipy.optimize import curve_fit
def g(x, A, mu, s): return A*np.exp(-(x-mu)**2/(2*s*s))
x = ks("A2:A100"); y = ks("B2:B100")
popt, _ = curve_fit(g, x, y, p0=[y.max(), x.mean(), 1])
popt.tolist()
