1. Getting Started

KherveSheet is an Excel-inspired spreadsheet workbench built on Python, PyQt5 and matplotlib. It combines familiar spreadsheet editing with scientific data analysis tools and publication-quality plotting.

Requirements

  • Python 3.12 or 3.13
  • PyQt5, matplotlib, numpy (core)
  • openpyxl (optional — Excel import/export with formatting, charts, images)
  • h5py (optional — native .ksheet format)
  • scipy (optional — Solver, trendlines, peak fitting, science tools)
  • lmfit (optional — advanced peak fitting models)
  • anthropic / openai / mistralai (optional — AI Chat sidebar)
  • pygit2 (optional — version control)

Launching

Run python KherveSheet.py or python -m khervesheet from the project directory.

Native File Format

KherveSheet saves workbooks as .ksheet files (HDF5-based). This format preserves all cell data, formatting, charts, images, shapes, equations, and version history.

2. Interface Overview

The main window follows a familiar spreadsheet layout:

Title Bar

Shows the application name, current file, and version string (e.g. KherveSheet v0.1.42+abc1234).

Menu Bar

Standard menu layout: File, Edit, View, Insert, Format, Formulas, Data, Science, Tools, Examples, Help.

Toolbars

  • Standard toolbar — New, Open, Save, Print, Undo, Redo, Solver, Curve Fitting, Science tools.
  • Font toolbar — Font family, font size, Bold, Italic, Underline, alignment (Left/Centre/Right), fill colour, font colour, borders, merge cells.
  • Plot/Insert toolbar — Chart type dropdown, table design, image, shapes, equation, symbol, sparkline, and insert controls (checkbox, dropdown, emoji, comment, note).

Formula Bar

Located below the toolbars: shows the active cell reference on the left and the cell contents/formula on the right. Click the cell reference to navigate to a specific cell. The formula bar is resizable — drag its bottom edge to expand for editing long formulas. Python cells (=PY) display a green background with a PY badge.

Grid

Columns labelled A, B, C, … Z, AA, AB, … and rows numbered from 1. Click a cell to select it; drag to select a range. Column and row headers can be resized by dragging their borders. The selection is shown with an Excel-style blue border rather than an opaque fill, keeping cell formatting visible.

Sheet Tabs

At the bottom: Sheet1, Sheet2, Sheet3, etc. Double-click a tab to rename it. Right-click for options. Use the + button or Insert > Sheet to add new sheets.

Status Bar

Shows a status message, a progress bar (when active), and a selection summary displaying Average, Count, and Sum of the selected numeric cells.

4. Editing Cells

Basic Editing

  • Click a cell and start typing to replace its contents.
  • Double-click or press F2 to enter edit mode (cursor within existing text).
  • Press Enter to confirm and move down, Tab to confirm and move right.
  • Press Escape to cancel the edit.

Selection

  • Click and drag to select a range of cells.
  • Hold Shift and click to extend the selection.
  • Hold Ctrl and click to select non-contiguous cells.
  • Click a column header to select the entire column; click a row header to select the entire row.

Navigation

  • Ctrl+Arrow — Jump to the next data boundary (edge of a filled region or first non-empty cell).
  • Shift+Arrow — Extend or contract the selection by one cell.
  • Ctrl+Shift+Arrow — Extend the selection to the next data boundary.

Clipboard

Fill Handle

Select one or more cells, then drag the small cross at the bottom-right corner of the selection to auto-fill adjacent cells. The fill handle works in all four directions (up, down, left, right) and supports number sequences, dates, and pattern continuation. Numbers are propagated with 2 decimal places.

Undo / Redo

Every editing action is undoable. Press Ctrl+Z to undo and Ctrl+Y to redo. The undo history covers cell edits, formatting changes, row/column insertion and deletion, sorting, merging, dropdown/hyperlink/spell-check edits, and more. The undo stack is capped at 60 steps to manage memory.

Rows & Columns

  • Insert > Row Above / Row Below — Insert a new row.
  • Insert > Column — Insert a new column.
  • Insert / Delete Cells — Shift only the selected columns, not entire rows.
  • Right-click a row header for Insert N Rows and Delete Row options.
  • Resize columns and rows by dragging the header borders, or use Format > Column Width / Row Height.

Merge Cells

Select a range and use Format > Merge Cells (or the toolbar button) to merge. Use Format > Unmerge Cells to reverse.

7. Python-in-Cell (=PY)

Type =PY( in any cell to write Python code that runs inside the spreadsheet. Python cells are highlighted with a green tint and a PY badge.

Getting Started

  • Type =PY( followed by your Python code and a closing ).
  • The last expression in the code block becomes the cell's value.
  • Multi-line code is supported — use the pop-out editor for longer scripts (click the expand button on the formula bar).

Pop-Out Python Editor

Click the pop-out button on the formula bar to open a full-size Python editor with:

  • Line numbers and syntax highlighting.
  • Autocomplete suggestions.
  • A Pick Cell button to insert cell references.
  • A toolbar with Run, Save, and formatting controls.
  • The editor stays open on Run so you can iterate quickly.

Accessing Spreadsheet Data

Use the ks() accessor to read data from the grid:

  • ks("A1") — read a single cell value.
  • ks("A1:C10") — read a range as a NumPy array.
  • ks_set("B5", value) — write a value back to the grid.
  • ks_image(fig) — embed a matplotlib figure as an image in the sheet.

Shared Namespace

All =PY cells share a single Python namespace. Functions and variables defined in one cell are available to others. You can also call Python functions defined in =PY cells from regular formulas.

Embedded Plots

Create a matplotlib figure in a =PY cell and it is automatically embedded in the sheet as a high-resolution image. Plots are rendered larger and sharper by default.

Auto-Refresh (Loop)

Enable per-cell auto-refresh to re-execute a Python cell at a set interval. This is useful for live-data dashboards — weather, stock tickers, news feeds, etc.

Network Access

Python cells can make HTTP requests (e.g. requests.get(), urllib) to fetch live data from APIs and web services.

Safety

An execution timeout prevents runaway cells from freezing the application. A watchdog detects and breaks infinite recursion before a native crash can occur.

Python Help

Open Help > Python Help for a built-in reference with 100+ examples covering data processing, scientific computing, plotting, simulations, and live data.

Series Properties

The Series Properties dialog lets you customise each data series independently:

  • Data tab — X/Y range, first row as header, per-series source mapping.
  • Line tab — label, plot type, line style (Solid/Dashed/Dotted/Dash-dot/None), width, colour.
  • Symbol tab — marker shape (Circle, Square, Diamond, Triangle, Plus, Cross, Star, etc.), size, fill colour, edge colour.
  • Fill tab — fill mode (None, Fill to Zero, Fill to Series), target series, colour, opacity.
  • Heatmap tab — colour map, interpolation, Z-axis limits (shown for Heatmap plots).
  • 3D Surface tab — colour map, wireframe style, elevation and azimuth angles (shown for 3D Surface plots).
  • Toggle series visibility with checkboxes. Add or remove series.

Categorical X-Axis

When the X column contains text or date strings, the chart automatically switches to a categorical X-axis with rotated labels for long text. Time strings (e.g. 8:00, 8pm) are parsed as numeric values with proportional spacing. Categorical axis settings persist across sessions.

Axis Properties

Double-click a chart or use the context menu to open the Axis Properties dialog with six configuration tabs:

  • Scale — Linear, Log, Symlog, or Logit. Auto or manual min/max limits. Inversion toggle.
  • Title — show/hide, text, colour, font, size (4–96 pt), bold/italic, rotation.
  • Tick Labels — show/hide, format (Auto, Decimal, Scientific, Standard Scientific, Engineering, Percentage, Plain), decimal places (0–12), prefix/suffix, colour, size, rotation.
  • Line & Ticks — spine visibility/colour/width, major tick direction/length/width/colour/count, minor tick subdivisions.
  • Grids — major/minor grid visibility, colour, opacity, style (Solid/Dashed/Dotted/Dash-dot), width.
  • Secondary Axis — independent spine, tick, label, and title configuration for the top/right axis, with user-adjustable title offset.
  • Z Axis — colour-limit controls for Heatmap charts (shown when applicable).

Annotations

Add draggable annotations via the context menu (Annotations > Add Text / Arrow / Line):

  • Text — draggable text label with a rounded box. Shows a dashed blue selection rectangle when clicked.
  • Arrow — annotation arrow from point to point with optional text. Shows filled blue circles at endpoints when selected.
  • Line — a finite line segment (like an arrow without arrowheads). Shows endpoint circles when selected.

Click an annotation to select it. Drag the body to move, or drag an endpoint circle to reposition one end. Press Delete to remove the selected annotation, or right-click for a context menu with Delete and Properties.

Text Properties

Edit the text content, font size, bold, italic, colour, rotation, and background box style.

Line / Arrow Properties

Edit line colour, width, line style (solid, dashed, dotted, dash-dot), and arrow style (multiple arrowhead shapes). Move endpoints by entering new coordinates.

Annotations are saved with the chart in .ksheet files and rendered correctly in print layouts.

Exporting Charts and Images

Right-click a chart and choose Export Image:

  • PNG at 300 dpi (suitable for presentations and reports).
  • PDF (vector format for publication).
  • SVG (vector format for web and editing).

Embedded images can also be exported as SVG or PDF via their right-click menu.

Plot Templates

Save a chart's visual styling (colours, fonts, axis settings) as a template via Plot Templates > Save as Plot Template. Apply a saved template to any chart to reuse the styling with different data.

10. Peak Fitting

Open via Tools > Curve Fitting or the toolbar button. The advanced fitting dialog supports multi-peak decomposition using lmfit models — ideal for spectroscopy, XRD, and XPS data.

Peak Functions (40+)

Built-in lmfit models include:

  • Gaussian, Lorentzian, Voigt, Pseudo-Voigt, Pearson VII/IV
  • Split Lorentzian, Moffat, Doniach–Sunjic
  • Skewed Gaussian, Skewed Voigt, Exponentially-modified Gaussian
  • Breit–Wigner–Fano, Log-normal, Student's t
  • Damped oscillator, Damped harmonic oscillator
  • Thermal distributions: Bose–Einstein, Fermi–Dirac
  • Step functions (linear/erf/atan/logistic), Rectangle
  • Exponential decay, Power law, Sine, Linear, Quadratic, Constant

Custom Functions

Define your own peak shape with a mathematical expression in x and free parameters. Available operations: exp, log, ln, sqrt, sin, cos, erf, erfc, gamma, and more. Parameters are automatically extracted from the expression.

Background Models

TypeModels
AnalyticConstant, Linear, Polynomial (degree 2–3)
Data-derivedShirley, Reversed Shirley, Active Shirley, Asymmetric Least Squares (ALS)

Parameter Control

  • Per-parameter value, min/max bounds.
  • Fix parameters (toggle vary on/off).
  • Tie parameters across peaks with expressions (e.g. p0+1.5 or 0.5*p1).

Fitting Workflow

  1. Select the data range using draggable delimiters on the plot.
  2. Add peak functions and set initial parameters.
  3. Choose a background model.
  4. Click Fit to run the optimisation.
  5. Inspect the live preview (data, components, total fit, residual) and fit report.
  6. Write fitted curves back to the sheet (background, components, total, residual).

Plot Controls

Zoom in/out, axis nudge buttons, zoom reset, zoom-to-selection, and grid toggle are available within the fitting dialog.

12. Solver

Open via Tools > Solver or the Solver toolbar button. The Solver finds optimal values for variable cells to minimise, maximise, or reach a target value in an objective cell, subject to constraints.

Setting Up

  1. Set Objective — click a cell in the sheet (e.g. $D$5) to set the objective.
  2. To — choose Max, Min, or Value Of (enter a target value).
  3. Variable Cells — click cells or enter ranges (e.g. A1:A5,C1:D3) for the values the solver can change.
  4. Constraints — add constraints using <=, >=, or = operators. Reference cells or enter numeric values.
  5. Non-negative — optionally restrict all variable cells to non-negative values.

14. Data Operations

Column Designations

Use Data > Set Column As to designate columns as X or Y data for plotting. Designated columns are used as the default data source when creating charts.

  • Data > Sort A → Z — Sort selected data in ascending order.

17. Version Control

KherveSheet includes built-in Git-based version control for tracking changes to your workbooks. Access via File > Version Control.

Automatic Versioning

Each save automatically creates a commit in a per-document Git repository, providing a complete history of changes.

Version History

Open File > Version Control > Version History to browse the commit history with a three-pane interface:

  • Commit list with a DAG graph showing branching and merges, timestamps, messages, and authors.
  • Commit details showing metadata and branch labels.
  • Diff viewer with syntax-highlighted added/removed lines.

Branches

  • View the current branch and switch between branches.
  • Create new branches from any commit.
  • Delete local branches (the current branch cannot be deleted).

Remote Sync

  • Push — push commits to a remote repository.
  • Pull — fetch and fast-forward from a remote.
  • Configure Remote — add or update the remote URL.

Restore

Click Restore this version in the history dialog to roll back the working tree to a previous commit. Save afterwards to record the rollback as a new commit.

Note: Version control requires the pygit2 library. If unavailable, the application remains fully functional without versioning features.

19. Printing

Press Ctrl+P or use File > Print to open the print dialog. Printing is WYSIWYG — what you see on screen (including charts, images, shapes, equations, and annotations) is what gets printed. Features include:

  • Print preview
  • Page setup (orientation, paper size, margins)
  • Scaling options
  • Print area selection
  • Embedded charts and annotations render in the print output
